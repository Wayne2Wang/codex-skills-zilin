# Current Venue-Compliance Protocol

Use this protocol only when a target venue and submission year are known or the user explicitly asks for compliance checking.

## Source requirements

Venue rules change. Browse the current official conference author instructions, call for papers, submission policies, and official template or style files for the specified year. Prefer the venue's own domain and link every rule used in the report. Do not rely on remembered limits or requirements.

If official instructions are unavailable or the user forbids browsing, mark venue compliance as unresolved rather than applying a previous year's policy.

## Checks

Check only rules relevant to the submission stage:

- paper and supplementary page limits and what counts toward them;
- required template/version, paper size, margins, fonts, columns, and line spacing;
- anonymity, acknowledgments, self-citation, repository, project-page, and supplemental-video rules;
- title/author metadata and conflicts between PDF and submission form where provided;
- dual-submission, prior-publication, arXiv, and workshop policies;
- ethics, limitations, societal-impact, human-subject, dataset, code, and reproducibility statements when required;
- bibliography placement and whether references are excluded from the page limit;
- file format, size, embedded fonts, accessibility, and PDF validation requirements;
- rebuttal-specific length, formatting, anonymity, and external-link restrictions when auditing a rebuttal.

Do not migrate the manuscript to another template unless the user asks. Report a verified deviation with the exact official rule, source link, and repair.

## Severity

- Classify violations that can cause administrative or desk rejection as **Required fix - submission blocking**.
- Classify ambiguous cases as **Resolve before submission** and quote or closely paraphrase the controlling rule.
- Keep general reviewer preferences separate from formal venue requirements.
